# Tend

A calm, minimalist to-do list. Tend to your day: capture tasks with optional descriptions, due dates and priorities, then work through **Today**, **Upcoming**, **Completed** or everything in **All Tasks**.

Built with Next.js (App Router), React, TypeScript and Tailwind CSS. Icons by [Lucide](https://lucide.dev). Tasks persist in your browser via `localStorage` — no account needed.

## Features

- Add, view, edit and delete tasks — deletion always asks first
- Optional description, due date and priority (low / normal / high) per task
- Views: Today (due or overdue), Upcoming, Completed, All Tasks
- Modern minimalist UI with micro-interactions; responsive from phones to desktop

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```
